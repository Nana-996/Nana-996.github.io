## 🌟 Overview

This is the official portfolio and interactive CV website of **Ms. Nana Ama Serwaa Akoto Djan**. It showcases her work at the intersection of healthcare, AI, software development, and renewable energy research.

Built with an editorial aesthetic featuring **Warm Cream (`#FBF8F3`)**, **Crisp White (`#FFFFFF`)**, **Rich Mocha (`#482C1D`)**, and **Espresso Brown (`#24160F`)**, with seamless switching to a dark **Espresso Velvet** mode.

## 🚀 Featured Projects

* **[CampusVerify](https://campus-verify.live/)**: A verified university student survey feed that eliminates bot responses and provides authentic student data collection through a fair credit exchange model. *(React, TypeScript, Supabase)*
* **[PharmacyGuard](https://pharmacy-guard.vercel.app/)** ([GitHub Repo](https://github.com/Nana-996/PharmacyGuard)): An AI-assisted decision support system for pharmacists and clinical students that checks prescriptions against clinical guidelines and drug-drug interactions. *(AI Decision Engine, React, Clinical Rx API)*
* **Novel Weaver**: An AI-assisted long-form story writing suite helping writers manage characters, chapter outlines, and plot continuity. *(React, TypeScript, LLM Integration)*
* **PharmaSim**: An interactive clinical pharmacy simulation game testing dosage calculations, contraindications, and patient counseling skills.
* **Amphibious Solar Rover for Water & Land Reclamation**: Lead researcher and mechanical designer for a semi-automated rover using Arduino turbidity sensing, roller conveyor trash skimmers, and duckweed phytoremediation. *(Awarded Certificate of Honour by Energy Commission & GES)*

## 🛠️ Tech Stack & Design System

* **Structure**: Semantic HTML5 (ATS-friendly print view, modal dialogs, accessible forms)
* **Styling**: Vanilla CSS3 with CSS Custom Properties, smooth micro-animations, glassmorphism, and responsive layout
* **Interactivity**: Vanilla JavaScript (ES6+) for theme toggling, recruiter focus filtering, interactive survey engine demo, and clinical scenario simulator
* **Typography**: Playfair Display (editorial serif) & Plus Jakarta Sans (clean geometric sans)
* **Icons**: FontAwesome 6.5.1

## 💻 Running Locally

No build tools or package managers required. Simply open `index.html` in any browser, or run a lightweight local server:

```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌐 Deploying to GitHub Pages

1. Go to your repository **Settings** on GitHub.
2. In the left sidebar, click **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Your site will be live at: `https://<your-username>.github.io/<repo-name>/` (or `https://<your-username>.github.io` if named `<username>.github.io`).
